# gmic.ai 官网改版说明

**开发版：** https://gmic-m.github.io/gmicai-n/main/index.html  
**线上版本：** https://gmic.ai/  
**分工：** 文案内容由 Yuki 提供，前端部署由 Luna 负责，我负责信息架构规划、UI 设计、视觉体系和页面搭建。

---

## Problem

旧版官网存在几个核心问题：

- **定位模糊：** 客户进来看不出 GMIC 和普通 ODM 的区别，页面像一个通用硬件公司的展示站
- **信息过载：** 各板块文字堆砌，客户需要花大量时间"阅读理解"才能找到关键信息
- **体验割裂：** 页面之间 UI 风格不统一，导航结构扁平，客户浏览时缺乏连贯感
- **转化路径不清：** 没有明确引导客户从"了解"走向"联系我们"的行动路径
- **产品展示不足：** 导航中产品只有文字列表，没有总览页，客户无法快速理解产品线全貌

## Insight

GMIC 的目标客户（ODM/HVAC/AI hardware）不是来"浏览网站"的，他们带着具体问题来：你能不能做定制硬件？你跟别家有什么不同？怎么合作？多久交付？

网站的任务不是展示公司有多全面，而是在最短时间内回答这些问题，然后把客户推向下一步动作——约会、要样机、要报价。

## Solution

核心方向：从"通用硬件公司展示站"转为"面向 AI 客户的 ODM 转化站"。

### 1. 导航重构 — 减少干扰，聚焦转化
- Products 下拉加入产品图片展示，客户不用点进去就能识别产品型号和样式
- 将 Blog、About Us、Contact Us、FAQ 收进 Company 二级菜单
- 导航只保留一个 CTA「Book a Demo」，把客户注意力集中到转化动作上

### 2. 信息架构重组 + 文案精简 — 用客户决策逻辑讲故事
- 重新规划首页信息流：认知 → 痛点 → 产品 → 差异化 → 行业场景 → 合作流程 → CTA
- 大部分板块从大段文字改为精简文字 + 图片搭配，让客户顺着页面往下看就能快速完成从"了解"到"行动"

### 3. 产品场景图 — 让客户看到"这是给我用的"
- 增加产品在具体行业中的使用场景图片
- 旧版只有产品本身的图，客户看不出设备在自己工作环境里怎么用；新版让产品和行业场景直接关联

### 4. 视觉体系升级 — 从"模板网站"到"专业硬件公司"
- 统一产品渲染图风格
- 加入视频背景、数据锚点（270+ programs shipped / 15+ years / US + Shenzhen）和认证徽标展示
- 全站 UI 统一配色、排版、组件和交互规范，消除页面之间的割裂感

### 5. 页面体系扩展 — 不同客户，不同入口
- 从单页网站扩展为 20+ 子页面：ODM/OEM 专页、各行业专页、产品详情页、合作流程页、FAQ
- 新增 View All Products 页面，让客户总览完整产品线，增加业务接触面

### 6. CTA 路径统一 — 每个页面都有下一步
- 全站 CTA 收拢为 Google Calendar 约会
- 多渠道联系入口（WhatsApp / Telegram / WeChat），确保不同地区客户都能找到联系方式

## Next Steps

- **真实素材替换：** 行业配图和部分板块仍使用 AI 生成图，需要客户现场实拍或工厂实拍替换
- **客户信任体系：** 缺少真实客户证言、案例和 logo 墙，需要 Yuki 配合获取
- **ODM 客户专属路径：** TROVA / HVAC / ODM 客户需要更直接的快速通道
- **深度内容迭代：** 子页面结构已搭建，内容需要根据真实客户反馈持续迭代
- **产品动态展示：** 参考竞品网站，产品页面可增加 360° 展示视频等动态内容，已在和 Evan、Keith 讨论
